# Maintainer Response Guide

## Triage

Acknowledge reproducible reports, ask for the smallest safe fixture, and label the
issue by impact and ownership. Close requests only with a factual explanation.

## Review responses

- Distinguish required changes from optional suggestions.
- Cite a failing test, contract, benchmark, or security boundary.
- Never imply that a contributor, employer, or external reviewer participated
  when they did not.
- For evaluator changes, require proof that candidate workspaces exclude golden
  patches and held-out tests.

## Security

Move sensitive details to GitHub private vulnerability reporting and avoid
reproducing untrusted patches on a credentialed machine.
