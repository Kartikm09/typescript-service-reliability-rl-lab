# Security Policy

## Supported versions

The latest tagged release and `main` receive security fixes.

## Reporting

Use GitHub's private vulnerability-reporting feature when available. Do not
include credentials, personal data, production targets, or exploit traffic in
an issue. A maintainer will acknowledge a report within five business days.

## Scope

This project executes candidate patches locally. The evaluator applies path and
timeout controls, but it is **not a hardened sandbox**. Run only code you trust,
preferably in an disposable VM or container without credentials or network
access. The examples and fixtures in this repository are entirely synthetic.
