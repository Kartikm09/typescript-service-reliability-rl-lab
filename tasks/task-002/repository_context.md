# Repository Context

The candidate receives the files under `baseline/workspace/` plus
`public_tests/`. The evaluator creates a separate internal test copy before
overlaying `held_out_tests/`. The full public portfolio repository contains
golden material for transparency, but candidate workspaces exclude it.

The codebase is a reduced, task-focused slice of the synthetic content-processing and notification platform
application. Read existing contracts and tests before editing.
